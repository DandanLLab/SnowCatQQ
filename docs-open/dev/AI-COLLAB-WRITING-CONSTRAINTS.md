# SnowCat 雪猫 · AI 协作写作的工程约束
## ——一夜 51 分钟成仓的幕后，以及怎么管住一个太会写文案的模型

> 本文兑现 #16 的承诺：把「AI 协作写作的工程约束」完整公开。为什么 README 雷霆、为什么通史能一夜写完、AI 在里面干了什么没干什么、以及最重要的一节——**怎么防止 AI 文案被四个不同的人认成四个不同的模型**（这事我们真踩过坑，详见第六节）。全部方法、全部翻车、全部摊开。

## 0. 先回答 #16 的原问题

- **模型**：市面随便买得到的，没有秘方。
- **提示词**：自己写的，而且**提示词不是这篇的重点**，工程约束才是。提示词决定 AI 第一次写成什么样，约束决定第二稿、第三稿、第一百稿能不能一直是人话。
- **雷霆程度和模型智力零相关**：你把同一个模型叫来让它写 QQ 机器人 README，它会给你「本项目是一个基于 XX 框架的高性能 QQ 机器人」。雷霆不起来，不是模型笨，是你没拦住它说套话。

## 1. 那一夜的时间线（诚实版）

51 分钟，11 commits。逐条拆：

| 时间段 | 干了什么 | AI/人分工 |
|---|---|---|
| 0-10min | 开仓、LICENSE、首批核心文件搬运 | 人决策，AI 整理 |
| 10-30min | README 首版 → 全新排版 → 双对比表 → B 站卡片嵌入 | AI 起草，**人逐句改**，AI 重排 |
| 30-45min | 公告、致谢、技术文档初稿 | AI 起草，人审 |
| 45-51min | 修排版、补链接、最后一遍通读 | 人 |

所以「AI 一夜写完仓库」是误读。准确说法：**人睡不着的夜里，AI 负责不让手停，人负责不让它写歪。**

## 2. 核心约束一：禁词表（雷霆的第一生产力是删词）

AI 写文案最大的毛病不是写不出，是**写得太像 AI**。我们定了一张禁词表，任何稿子过审前先杀这几类词：

- **性能吹**：高性能 / 极致 / 丝滑 / 强大 / 卓越
- **生态话术**：赋能 / 生态 / 闭环 / 打通 / 全链路
- **营销腔**：旨在 / 致力于 / 助力 / 深耕
- **假谦虚**：抛砖引玉 / 不足之处 / 还请指正（用在乐子文里是灾难）
- **AI 味连接词**：综上所述 / 总而言之 / 值得注意的是 / 不可否认

杀完之后 AI 的第一反应是写不出话。**对，写不出话是好事**——这时候它才会去找具体的、有画面的、狂的说法。比如把「高性能机器人框架」逼成「雷霆东西」「赛博开盒传奇」这种词不是 AI 天生会说的，是禁词表挤出来的。

## 3. 核心约束二：人工终审（AI 的话永远是草稿）

规则只有一条：**AI 产出的每一个字，发出前必须有一个碳基生物读过并且愿意为它负责。**

实操上是三层：

1. **AI 起草**——快，量足，雷霆潜质高
2. **人改**——逐句过，改的是「这句话像不像我们说的」而不是「这句话对不对」（对不对它一般都对）
3. **AI 重排**——人改完的稿子让 AI 做排版/链接/格式，禁止它趁机改字（下文有翻车案例）

为什么人改的重点是「像不像我们说的」：因为 AI 的知识是全网的平均数，它的默认文风是**所有人的平均**，而一个活的项目必须有**自己的嗓音**。嗓音只能人来定，AI 负责把嗓音放大。

## 4. 核心约束三：事实闸（AI 写事实必须挂证据链）

乐子可以瞎编，事实不行。我们的规则：

- AI 写的每一条**可验证事实**（版本号、日期、commit 数、技术结论）必须带出处，人拿出处抽验
- 抽验不过整段打回，AI 不许凭记忆补——**宁可写「待核实」，不许编一个像的**
- 这个闸救过我们至少三次，包括本仓库自己被 grep 出的那条 QQ 号残留（#14）——讽刺的是，整活帖用的正是我们要求自己用的方法：每条结论挂文件行号。**敌人用我们的军规打的我们，说明军规是对的。**

## 5. 核心约束四：一致性与嗓音（一个人写一个项目）

51 分钟里 README 被重排了两次、公告改了三版，全是同一个 AI 同一晚上写的，但今天回头读，几乎看不出是同一支笔——因为我们执行了一个粗暴规则：

**每个文档开写前，先给 AI 一段「嗓音样本」（我们已发布文案里最像我们的三段），要求它模仿这个嗓音续写，禁止自由发挥。**

没有嗓音样本的 AI 就像没有单位的物理题：答案看着都对，放一起全是四不像。

## 6. 翻车实录：被四个不同的人认成四个不同的模型

这事必须写，因为太好笑了且太典型了。

开源当晚，issue 区先后有四位师傅「鉴定」我们的 AI 底座——分别认成了四个完全不同的模型。四个人，四个答案，零个对的。

事后复盘，原因就一条：**当晚的文案是四个小时的连续写作，AI 在不同时段被喂了不同的上下文，文风漂移**。凌晨的 README 和清晨的公告，用词习惯、段落长度、狂的方式都不一样——像极了同一个人类作者熬夜前后的笔迹差异。

也就是说：**AI 的文风漂移大到连人类都按「多模型协作」来解释了。** 这不完全是坏事——它说明我们的稿子没有「标准 AI 味」，但也说明约束里必须加一条：

> **长篇连续写作必须共享同一份「文风锚」文件（嗓音样本+禁词表+已发布稿），每一段开写前重读。**

加了这条之后，通史（#13 里被重构了五层的那篇）从头到尾一个嗓音，没人再猜错模型——大家改猜我们是不是「能工智人显著修改」了，这个描述更接近事实。

## 7. 给想复刻的人的清单

浓缩成一张表，照抄可用：

| 约束 | 一句话 | 翻车形态（不做的后果） |
|---|---|---|
| 禁词表 | 杀掉所有 AI 套词，逼出具体的狂话 | 文案像市面上每一个项目 |
| 人工终审 | AI 的字永远是草稿，发出前人负责 | 出事了锅找谁？ |
| 事实闸 | 每条事实挂出处，抽验不过打回 | QQ 号写进开源脚本（#14 实锤，别学） |
| 嗓音锚 | 每段开写前重读样本+禁词表 | 四个人认出四个模型（第六节实锤） |
| 单一事实源 | 文档数据（星数/版本/日期）从仓库读，不许 AI 凭记忆 | 乐子变事故 |

## 8. 最后一段

这一夜我们学到的事，和评论区学到的是同一件：**AI 把「写出来」的成本降到几乎为零之后，剩下的全部价值都在「写得对」和「写得像自己」上。** 前者靠事实闸，后者靠嗓音锚，两者都不是模型给的，是流程给的。

模型买得到，提示词学得会，**约束是自己的**。
